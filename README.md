# Porphyra

A free and open-source church management platform from Acts 2:44 Technology.

## Development

```sh
bun install
cd server/api && uv sync && cd ../..
bun run dev
```

The web application runs at <http://localhost:3000>. The auth service runs at port 4000 and the API at port 8000. Expo launches Planning, Volunteer, and Kiosk on ports 8081–8083.

The initial development account is `dev@a244.tech`.
